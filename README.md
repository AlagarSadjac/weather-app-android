## 📱 About The App
This app provides a streamlined digital interface to track instant weather conditions worldwide without clutter, featuring:
* 🌡️ **Real-Time City Temperature & Weather Metrics**
* 🔍 **Global City Search with Instant API Querying**
* ⚡ **Fast Asynchronous Network Calls via Retrofit**

Engineered with a minimalist UI, smooth performance, and an intuitive user-friendly design.

---

## ✨ Features
* 🌤️ **Live Weather Forecasts:** Fetches accurate temperatures, conditions, and atmospheric data using OpenWeatherMap API.
* 🔎 **Instant City Search:** Quickly query any city globally to fetch real-time weather reports within seconds.
* 🛡️ **Graceful Error Handling:** Comprehensive checks for offline states, bad connections, and invalid location queries.
* ⚡ **Fast & Lightweight:** Optimized network serialization ensuring minimal bandwidth and battery consumption.
* 📱 **Clean UI:** Centered, distraction-free XML interface focused on optimal readability.

---

## 🛠️ Built With
* **Language:** Java
* **IDE:** Android Studio
* **Networking Library:** Retrofit 2 (REST API Client)
* **Data Source:** OpenWeatherMap API
* **Layouts:** XML Layouts & ConstraintLayout
* **Build System:** Gradle
* **Version Control:** Git & GitHub

## 🚀 How To Use
1. Download and install the APK using the download button above.
2. Launch the app and type any city name into the search bar.
3. Tap search to instantly see current temperatures and weather updates 🌦️.

---

## 🎯 Purpose
The primary objective of this application is to demonstrate RESTful API consumption and asynchronous network request processing using Retrofit within a clean native Android architecture.
